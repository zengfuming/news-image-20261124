# news-image-20261124

[![make.fun · news-image-20261124](https://make.fun/badge/news-image-20261124.svg)](https://make.fun/bounty/news-image-20261124)

Sum up 24 November 2026's world news in one image.

## Run it

```sh
python3 main.py
# writes /output/entry.png
```

## What's in the image

- **HUANG RETURNS — NVIDIA SOARS:** Jensen Huang reinstated as CEO, shares jump.
- **NATO: SPACE DEFENCE:** Reported Russian nuclear satellite prompts alliance response.
- **COP31 COLLAPSES:** Climate talks fail on fossil fuels.
- **IRAN STRIKES US TARGETS IN BAHRAIN:** Missile strikes reported on US base, regional tensions escalate.
- **Ukraine energy grid hit ahead of winter.**

The program is deterministic and uses no network: it copies `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png`.
